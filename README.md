# دکوری آنلاین — فروشگاه دکوری و اکشن فیگور

سایت فروشگاهی کامل با پنل مدیریت و پنل فروشندگان.

## نحوه اجرا

فقط فایل `index.html` را در مرورگر باز کنید (یا با یک سرور ساده مثل Live Server).

داده‌های فروشگاه، محصولات، سفارش‌ها، مشتری‌ها، تنظیمات و تغییرات پنل در **Supabase** ذخیره و بین همه دستگاه‌ها همگام می‌شوند. `localStorage` فقط برای کش سریع مرورگر استفاده می‌شود؛ سبد خرید و نشست ورود کاربر محلی هستند.

## ورود مدیریت

- آدرس: `admin/login.html`
- **رمز عبور: `2012`**

در پنل مدیریت می‌توانید:
- نام سایت، لوگو، رنگ اصلی، متن‌های صفحه اصلی، درباره ما و اطلاعات تماس را تغییر دهید
- فروشنده جدید اضافه کنید (ایمیل یا شماره + تولید خودکار رمز عبور)
- محصولات و دسته‌بندی‌ها را مدیریت کنید

## ورود فروشنده

- آدرس: `seller/login.html`
- با ایمیل/شماره و رمزی که مدیر ساخته وارد شوید

فروشنده‌های پیش‌فرض برای تست:
| نام | تماس | رمز |
|-----|------|-----|
| فروشگاه کلکسیون | collection@example.com | seller123 |
| دکوراسیون آرین | arian@example.com | seller456 |

## امکانات

- طراحی مدرن و تیره (Dark)
- ریسپانسیو
- سبد خرید
- فیلتر و جستجو
- افزودن/ویرایش/حذف محصول توسط فروشنده
- تغییر کامل ظاهر سایت از پنل ادمین بدون کدنویسی
