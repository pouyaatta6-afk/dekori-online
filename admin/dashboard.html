کدهای اختصاصی

اگر می‌خوای ظاهر یا رفتار سایت رو با کد سفارشی تغییر بدی، اینجا بنویس. کدها روی صفحه اصلی اعمال می‌شن.

این CSS به انتهای صفحه اضافه می‌شود و می‌تواند استایل‌های پیش‌فرض را override کند.
این JavaScript بعد از لود صفحه اجرا می‌شود. از document و window آزادانه استفاده کن.
این HTML دقیقاً بعد از باز شدن <body> قرار می‌گیرد (مثلاً برای اسکریپت آنالیتیکس یا نوار سفارشی).
این HTML قبل از بسته شدن </body> قرار می‌گیرد.
کدها ذخیره شدند!
